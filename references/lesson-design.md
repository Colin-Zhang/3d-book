# 把一节课本设计成一课 3D（各科通用）

## 1. 挑一个能演的东西

从原件里挑**一个**主角（实验、模型或场景），按这个顺序选：

1. 课本自己让学生做、让学生看的（“实验”“想想做做”“动手试”“活动”）。
2. 能立在书页上：桌上能摆的装置或模型。人物、大场景写进正文一句话就行。
3. 会动、动起来能看出结论：有一个过程，结束有一个能比的结果（读数、位置、颜色、状态）。
4. 能调一两个参数，调完结果不一样。

具体搭什么、怎么算，看这一科的 `subjects/<科目>/guide.md`。

## 2. 跨页和课本样式

- **原书一页 ≈ 一个跨页**。原书一节有两三个实验 / 活动，就做两三个跨页（导出 `spreads: [...]`），翻页时装置会折下、弹起。范例：第 4 节《机械能及其转化》两页 → 跨页 ①“问题：铁锁会打到鼻子吗”② “想想做做：滚摆”。
- **照原书排字（推荐）**：`pages.blocks` 按原书顺序一块一块排（“问题”框、正文段、小标题、“想想做做”、结论框、图注、答案贴纸），右页下半用 `right.blocks`（从 `right.top` 像素开始，1450 以下不会压到立体装置）。原书一页的字放不下时，左页放前半、右页下半放后半。写法见 `api.md`“按块排版”。下面那几个固定字段（`predict` / `body` / `try`）是不照原书时的简易写法。
- **书页用 `style: "textbook"`**：左页顶上是蓝色节号标签（`section: { no: "第4节", title: "机械能及其转化" }`），预测放在“问题”框里，动手放在“想想做做”框里，跟课本一个路数。图注里的图号照原书（“图 11.4-1　摆动的铁锁”）。颜色默认课本蓝，`accent` 可以改。
- 页眉、页码照原书写（`chapter`、`pageNo`）。

## 3. 字怎么写（`meta.pages`）

左页从上到下是：标题 → 一句问题式副标题 → 正文 → ① 先猜一猜 → ② 动手试 → ③ 掀开看答案（盖着一张黄色贴纸）。

| 字段 | 写什么 | 长度 |
| --- | --- | --- |
| `title` | 实验名，名词短语（“钢球撞木块”） | ≤ 8 字 |
| `subtitle` | 这节课的问题（“动能跟什么有关？”） | ≤ 12 字 |
| `body` | 先说看得见的现象，再给概念的名字。用自己的话，不抄课本 | ≤ 80 字 |
| `predict.q` | 一个能凭直觉猜的问题，跟“动手试”直接对得上；原书开头有“问题”就照它的意思改写 | ≤ 40 字 |
| `predict.options` | 三个选项：一个对的、一个最常见的错觉、一个别的。每个 ≤ 6 字（短了排一行） | 3 个 |
| `try` | 右页上点哪里、调什么、比什么 | ≤ 50 字 |
| `answer.text` | 结论 + 为什么，用自己的话 | ≤ 60 字 |
| `answer.extra` | 可选：手写体补一句（“高中会学：Eₖ = ½ m v²”） | ≤ 20 字 |
| `chapter` / `lessonNo` / `pageNo` | 页眉、页码 | |
| `section` | 课本样式的节号标签：`{ no: "第4节", title: "机械能及其转化" }` | 标题 ≤ 10 字 |
| `subtitle` | 课本样式里写在标题下面一行 | ≤ 20 字 |
| `right.caption` | 图注，图号照原书 | ≤ 22 字 |
| `right.hint` | 怎么玩（拖哪里、点哪里） | ≤ 26 字 |
| `right.figure(ctx, o)` | 可选：印在右页下方的线描或小框（区域 `o.x, o.y, o.w, o.h`，约 1236×330 像素；别跟立起来的装置、开关、卡片重叠） | |

左页放不下时截图会报“左页字太多”，删短 `body`、`try`、`answer`。

## 4. 交互和声音

- **能用手做的就让人用手做**：拖钢球到斜面上某个高度、拖铁锁到鼻尖前、拖滚摆往上卷——用 `draggable(物体, { onStart, onMove, onEnd })`，松手（`onEnd`）就开始。
- **开关立在书页上**：比如“空气阻力 开/关”，用 `pageSwitch({ label, onChange })`，放在装置前面的空白处。
- 底部 `controls` 只放两三个离散选项（大钢球 / 小钢球、推一下 / 不推），最多两组。“开始”按钮的字写在 `meta.goLabel`（“松手 ▶”“开始反应 ▶”），这一页不需要就写 `null`。
- 装置上能点的东西放进 `clickables`，点了调用 `click(obj)`。
- **每个动作都有声音**：`sfx.click()`、`knock(力度)`、`creak()`、`beep()`……持续的声音（滚动、摆动的风声、冒泡、倒水）用 `sfx.loop("roll").set(0–1)`，每帧按速度设一次，停下设 0。翻页、掀贴纸、拨开关的声音引擎已经有了。

## 5. 镜头和录屏

- 引擎自带 `overview`（整本书）和 `page`（左页）。每课再加 2–3 个：装置近景、装置中景、能量近景。
- `clip`：录屏时先设哪些参数、勾哪个预测、从哪个镜头推到哪个镜头、第几秒开始、总长几秒。6–8 秒就够。

## 6. 科目相关的

实验怎么搭、要画哪些量、怎么算，看 `subjects/<科目>/guide.md`（比如物理：`subjects/physics/guide.md`，范例课 `template/src/lessons/kinetic.js`）。
