# 画面规则和截图检查清单

## 规则

1. **装置要大**：立在右页上，x 在 0.08–0.99、z 在 -0.45–0.45（右页是 x 0–1、z -0.69–0.69，朝镜头是 +z），高 0.25–0.45。太小就是“书上摆了个小玩具”。装置后面留 z ≈ -0.2 给能量量筒。
2. **白模 + 排线**：所有实物用 `hatchMat()`。白木 `#efe6d5`、浅木 `#e8d6b4`、金属 `#cdd5dc`（球、圆柱用 `mode: "uv"`，线顺着表面走）。
3. **颜色只给两种东西**：能量（量筒、管子）和能点的东西（橙色 `#f07a2a`）。别的都是白、浅木、浅灰。
4. **描边**：方的用 `edges()`，圆的（球、圆柱）用 `hull()`。大平面用 `BoxGeometry`，不用圆角盒子（排线会出锯齿）。
5. **影子落在书页上会自动变成排线**，所以东西要 `castShadow = true`。
6. **字**：书页正文 ≥ 42px（引擎已定），标签卡 `tagCard` 第一行名称、第二行数值，数值字 ≥ 46px；手写小字用 `label()` + `billboard`（面向镜头）。
7. **不要动引擎的灯、桌子、书**，统一的质感就是靠它们：窗光（带窗格图案的主光）、影子落在书页上变排线、液体颜色映到周围（量筒自带）、翻页时装置先线稿再上色，都是引擎做的。
8. **开关、读数卡、手写字别压在右页印的线描或说明框上**：右页下方（z 0.25–0.47）留给 `figure`，开关和卡片放在装置前面那一条（z 0.28–0.33）或左边。
9. 一个画面里能读的字不超过五处：标题、读数卡、量筒标签、高度之类的一个小标注。

## 截图检查清单（每次交付前逐条对）

| 截图 | 看什么 |
| --- | --- |
| 全景 `overview` | 整本书都在画面里；装置在右页中间、没有伸出页边；左页字都在页内，没有被贴纸盖掉的标题 |
| 动作进行中 | 东西在动的位置对（没穿进斜面、桌面）；至少一根管子在流；量筒数值加起来 ≈ 一开始的总能量 |
| 结束 | 读数卡出现、数值合理（量级跟真实实验对得上）；记号留在尺子 / 刻度上；按钮恢复可点 |
| 近景（可选） | 排线、描边清楚，没有大块灰色或纯黑；标签卡的字能读 |
| 每个跨页 | 用 `["goto", n]` 截一张全景：左页照原书的节号、问题、图号；装置弹起来了、没压到右页的印刷图 |
| 拖拽 | 用 `["drag", 名字, [...]]` 截拖到最远处的样子：拖不出合理范围（不穿过鼻子、斜面、桌面） |

截图命令见 `api.md`。终端里有“页面报错”或“左页字太多”的警告，先修再看图。
