# 物理科目包

适用：初中、高中物理里能在桌上演的实验——力学（斜面、小车、摆、弹簧、杠杆、滑轮、浮力）、能量转化、简单的热学（加热、温度计）。范例课：`template/src/lessons/kinetic.js`（钢球撞木块）。

## 1. 实验搭成什么样

| 课本里 | 搭成 | 能调的 | 结束看什么 |
| --- | --- | --- | --- |
| 斜面、滚动 | 三棱柱斜面（`ExtrudeGeometry`）+ 两侧挡条 + 球 | 高度、球的质量 | 滑多远（刻度尺 + 记号） |
| 摆 | 铁架台 + 绳 + 摆锤（铁锁、小球），摆锤能拖（`draggable`） | 拉开的角度（拖）、推不推、空气阻力（`pageSwitch`） | 摆回来最高到哪（竖尺上的记号） |
| 滚摆 | 立柱 + 横梁 + 两根线 + 轮（轴沿 z，轮面对着镜头才看得出转），轮能往上拖 | 卷多高（拖）、空气阻力 | 每次回到多高（竖尺记号） |
| 弹簧 | 圆柱螺旋线（`polyline` 画螺旋）+ 物块 | 压缩量、劲度 | 弹出去多远 / 多高 |
| 杠杆、滑轮 | 木条 + 支点三角 + 挂钩码 | 力臂、钩码个数 | 平不平衡（指针） |
| 浮力 | 烧杯（透明圆柱，同量筒做法）+ 水面 + 物块 | 物块密度 | 浮着还是沉底、露出多少 |
| 加热 | 烧杯 + 酒精灯（橙色火焰 = 能点的东西）+ 温度计 | 加热时间 | 温度读数 |

## 2. 能量量筒

- 用 `makeEnergy()`（见 `references/api.md`），放在装置后面（右页 z ≈ -0.2），最多 4 种。
- 颜色已经定好：重力势能 `pe` 蓝、动能 `ke` 橙、内能 `q` 红、弹性势能 `ee` 绿、化学能 `ch` 紫。
- `pipes` 按能量流动的方向连，比如势能 → 动能 → 内能。来回转化（摆）用 `flow(i, v, -1)` 让管子倒着流。
- `max` 设成这一课可能出现的最大总能量，液面才不会顶到头或者看不见。
- 每一帧 `energy.set({...})` 一次；正在转化的那根管子 `energy.flow(i, 0–1)`。

## 3. 物理怎么算

- 用真实单位（米、千克、秒、焦）算；场景里 1 个单位 = `K` 米（范例 K = 1，书页宽 1 米，装置是“放大”的）。
- 动作太快就慢放：`SLOW = 0.3` 表示真实 0.3 秒演 1 秒。
- 固定小步长积分（1/600 秒），别直接用一帧的 dt。
- 能量守恒：量筒里各种能量加起来 = 一开始的总能量；有摩擦、空气阻力时，少掉的进“内能”。
- 状态机：`ready`（等着）→ 动作中 → `done`（结束，出读数卡、留记号）。
- 结束的读数要能比：保留上一两次的记号（范例在刻度尺上留“3号·大”这样的铅笔线）。

## 4. 范例对照（`lessons/kinetic.js`）

| 课本 | 3D 里 |
| --- | --- |
| “探究动能跟哪些因素有关”的实验 | 斜面 + 钢球 + 木块 + 刻度尺 |
